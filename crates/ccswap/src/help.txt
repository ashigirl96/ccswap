usage: {prog} <command> [args] [options]

Multi-Account Switcher for Claude Code

Commands:
  {prog} help                       show this help
  {prog} list                       list managed accounts
  {prog} status                     show current account
  {prog} switch                     rotate to the next account
  {prog} switch <num|email>         switch to a specific account
  {prog} add                        add the current account
  {prog} add-token [TOKEN|-]        register a setup-token or API key
  {prog} remove <num|email>         remove an account
  {prog} disable <num|email>        hold an account out of auto-rotation
  {prog} enable <num|email>         return a disabled account to rotation
  {prog} run <num|email> [-- ...]   run as an account, this terminal only
  {prog} run                        run the current dir's mapped account
  {prog} map <num|email> [path]     map a directory to an account
  {prog} map                        list directory mappings
  {prog} unmap [path]               remove a directory mapping
  {prog} alias <num|email> <name>   set a short alias for an account
  {prog} alias <num|email> --unset  remove an account's alias
  {prog} alias                      list all aliases
  {prog} swap <a> <b>               exchange two accounts' slot numbers
  {prog} move <a> <slot>            assign an account to a slot (swaps if taken)
  {prog} auto                       auto-switch when nearing rate limits
  {prog} config [set KEY VALUE]     show or change settings (settings.json)
  {prog} unclaimed [--purge ID]     list or drop stashed credential entries
  {prog} export <path>              export accounts
  {prog} import <path>              import accounts
  {prog} tui                        interactive dashboard (also: bare {prog})
  {prog} watch                      dashboard, opened on the live watch page
  {prog} menubar                    macOS menu bar app
  {prog} menubar --install-service  keep the menu bar running via launchd
  {prog} widget --install           add the desktop widget (ccswap.app)
  {prog} upgrade                    self-upgrade to latest
  {prog} purge                      remove all claude-swap data

Codex CLI accounts (numbered apart from Claude accounts):
  {prog} codex add                  register the current Codex login
  {prog} codex list                 list managed Codex accounts
  {prog} codex switch [num|email]   switch the Codex login (next one without an argument)
  {prog} codex --help               show the Codex commands and options

Aliases: ls=list  rm=remove  update=upgrade

options:
  -h, --help            show this help message and exit
  --version             show program's version number and exit
  --debug               Enable debug logging
  --token-status        Show source-labelled OAuth token diagnostics (use with
                        'list')
  --json                Emit machine-readable JSON to stdout (use with 'list',
                        'status', or 'switch'). See README 'JSON output for
                        scripting'.
  --strategy {best,next-available}
                        With bare 'switch': pick the target by remaining 5h/7d
                        quota. 'best' jumps to the account with the most
                        headroom; 'next-available' rotates to the next
                        account, skipping any at their limit
  --model NAMES         With 'switch --strategy': also count these models'
                        per-model weekly limits when comparing accounts
                        (comma-separated display names, or 'all'). Defaults to
                        the autoswitch.model setting
  --slot NUM            Specify slot number when adding account (use with
                        'add' or 'add-token')
  --email EMAIL         Email address for the account. Optional with 'add-
                        token'; defaults to setup-token-{slot}@token.local (or
                        api-key-{slot}@token.local for API keys) since these
                        tokens carry no real email metadata.
  --account NUM|EMAIL   Limit export to one account (use with 'export')
  --alias NAME          Set a short display alias for the account (use with
                        'add')
  --force               Overwrite existing accounts during import; with
                        'switch <num|email>', activate the stored credentials
                        without backing up the current login first
  --full                Include full ~/.claude.json in export (default:
                        oauthAccount only)
  --install-service     With 'menubar': install a launchd LaunchAgent so the
                        menu bar starts at login and restarts on crash (macOS)
  --uninstall-service   With 'menubar': stop the LaunchAgent and remove its
                        plist (macOS)
  --service-status      With 'menubar': report whether the LaunchAgent is
                        installed and running

Flags combine with subcommands:
  {prog} switch --strategy best           # pick the account with most quota left
  {prog} switch --strategy next-available # rotate, skipping rate-limited accounts
  {prog} switch user@example.com
  {prog} list --token-status
  {prog} list --json
  {prog} add --slot 3                      # add to a specific slot
  {prog} add-token sk-ant-oat01-... --email me@example.com
  {prog} run 2 -- --resume                 # forward args after '--' to claude
  {prog} auto --once                       # single auto-switch tick (cron-friendly)
  {prog} config set autoswitch.threshold 80

The original flag spellings ({prog} --switch, {prog} --list, ...) keep working.
