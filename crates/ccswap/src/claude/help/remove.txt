usage: {prog} claude remove [-h] [-y] [--debug] NUM|ALIAS|EMAIL

Remove a managed Claude Code account and its stored credentials. Asks first
unless -y is given.

positional arguments:
  NUM|ALIAS|EMAIL  Account to remove

options:
  -h, --help       show this help message and exit
  -y, --yes        Remove without asking
  --debug          Enable debug logging
