usage: {prog} alias [-h] [--unset] [--debug] [NUM|EMAIL] [NAME]

Set, remove, or list a short display alias for an account. Once set, the alias can be used anywhere an account number or email is accepted (switch, remove, run, map).

positional arguments:
  NUM|EMAIL   Account to alias (number or email). Omit to list aliases.
  NAME        Alias to set (letters, digits, ., -, _; not purely numeric).

options:
  -h, --help  show this help message and exit
  --unset     Remove the account's alias
  --debug     Enable debug logging

Examples:
  {prog} alias 2 dev
  {prog} alias user@example.com dev
  {prog} alias 2 --unset
  {prog} alias                         # list all aliases
