usage: {prog} claude switch [-h] [--strategy {best,next-available}] [--model NAMES]
                            [--force] [--json] [--debug]
                            [NUM|ALIAS|EMAIL]

Switch the Claude Code login to another managed account. Without an account,
rotate to the next one in sequence.

positional arguments:
  NUM|ALIAS|EMAIL       Account to switch to. Omit to rotate.

options:
  -h, --help            show this help message and exit
  --strategy {best,next-available}
                        Without an account: pick the target by remaining
                        5h/7d quota. 'best' jumps to the account with the
                        most headroom; 'next-available' rotates to the next
                        account, skipping any at their limit
  --model NAMES         With --strategy: also count these models' per-model
                        weekly limits when comparing accounts (comma-separated
                        display names, or 'all'). Defaults to the
                        autoswitch.model setting
  --force               With an account: activate the stored credentials
                        without backing up the current login first
  --json                Emit machine-readable JSON to stdout. See README 'JSON
                        output for scripting'.
  --debug               Enable debug logging

Examples:
  {prog} switch                            # rotate to the next account
  {prog} switch 2
  {prog} switch user@example.com
  {prog} switch --strategy best            # the account with most quota left
  {prog} switch --strategy next-available  # rotate, skipping rate-limited ones
